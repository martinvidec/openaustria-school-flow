🎓 SchoolQuest — Volksschule 1–4

Prototyp — Work in Progress

Was wird hier entstehen?

Eine Lern-Quest-App für die österreichische Volksschule (Stufen 1–4) auf Basis des neuen Lehrplans (BGBl. II Nr. 1/2023): vollständige Inhalte + interaktive Quests, damit Lehrer ohne zusätzliche Materialien unterrichten können.

MVP-Fokus: Deutsch & Mathematik (3.–4. Stufe).

Nächste Schritte

  1. Konzeptdokument & Spec (Workflow: concept-analysis-spec)
  2. Datenmodell: Fach → Stufe → Kompetenz → Quest (aus Lehrplan-Research)
  3. Quest-Engine (Browser-only, localStorage)
  4. Inhalts-Pipeline aus research/vs-lehrplan-spec/
