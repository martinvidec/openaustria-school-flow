SchoolFlow — Prototypen

Eigenständige UI-Prototypen (Sidecars) zum Hauptprojekt OpenAustria SchoolFlow. Rein statisch: kein Backend, keine Accounts, alle Daten bleiben im Browser.

Stundenplaner (Volksschule)

Berechnet den kompletten Stundenplan einer österreichischen Volksschule direkt im Browser — Stammdaten erfassen, Machbarkeit prüfen, Plan lösen und je Klasse / Lehrkraft / Raum ansehen.

Prototyp öffnen

Lokal starten: python3 -m http.server im Ordner prototypes/ ausführen und http://localhost:8000 öffnen (direktes Öffnen via file:// funktioniert wegen ES-Modulen nicht).
